# OpenCtrlC Homebrew Tap

Install the OpenCtrlC CLI on macOS or Linux:

```sh
brew install ponponon/tap/openctrlc
```

Upgrade with `brew upgrade openctrlc`. This is a project-maintained third-party tap; it is not part of `homebrew/core`.

The Formula supports macOS Apple Silicon and Intel, plus Linux ARM64 and x86_64. It downloads versioned OpenCtrlC release assets and verifies each archive with SHA-256.

GitHub Actions checks for a new stable release every six hours and updates the Formula automatically. You can also run the **Update Homebrew Formula** workflow manually from the Actions tab.
